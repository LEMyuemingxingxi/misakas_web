第一章 本书概述 这一章主要讨论人工智能逻辑研究什么和如何研究。 人工智能是指机器能够展示的智能。粗略地讲，所有通过计算的方法来实现智能行为的 研究都可以纳入人工智能领域。从方法论的角度看，实现人工智能的途径主要包括符号主义 方法和亚符号主义方法。前者运用各种符号语言来表示知识，并通过符号演算来做出判断和 决策[1]。后者基于统计学理论从数据中获得各种模式或规律。符号主义方法涉及到概念、判 断、推理等抽象概念的显式表达。由于采用人类可理解的逻辑语言来表示陈述性知识，且采 用与人类思维相对应的逻辑推理来获得结论，符号主义方法可以描述各类抽象问题，其通用 性和可解释性好。相反，亚符号主义方法不涉及抽象概念的显式表达，而重点在于发现数据 背后的模式和规律[2]。因此，亚符号方法不需要知识表示，而采用基于统计的学习，如贝叶斯 学习、神经网络学习、强化学习、大语言模型等。这种方法一般建立在大数据的基础上。亚符 号方法基于概率统计，可以处理大数据，但其可解释性差，不擅长于解决涉及复杂逻辑关系 的抽象问题。 由此可见，符号主义方法和亚符号主义方法有各自的优缺点，互补性强。一方面，符号 主义方法所依赖的知识除了人工构建，更需要通过机器学习来自动获取。另一方面，为了提 高亚符号主义方法的可解释性，需要采用人类可理解的符号语言来表示该方法内部的决策要 素和过程。因此，除了符号主义方法，可解释的亚符号主义方法也涉及到知识的表示、获取 和推理问题。换句话说，知识的表示和推理是实现高水平人工智能的核心之一，而逻辑学是 知识表示和推理的基础。 鉴于上述原因，《人工智能逻辑》这门课程的主要内容将涵盖可以支持上述两类方法所涉 及知识的表示和推理的逻辑学基础理论。 推理研究一组命题集合和一个新命题之间的关系。前者为前提，后者为结论。依据某种 推理关系，可以从一组前提推出某个结论。我们把前提、结论和推理关系组成的一个结构称 为论证。 在人们的日常生活中，推理主要包括如下三种情形。第一，从已有知识推出新知识。第 二，从案例归纳出新知识。第三，从所观察的现象和已有知识寻求最佳解释。相应地，有如下 基本推理类型：演绎推理（包括具有单调性的演绎推理系统和具有非单调性的扩展演绎推理 系统）、归纳推理和溯因推理。 通常，人们除了在命题层面进行上述推理，还在论证层面进行推理。前者从已知命题推 出新命题，后者从已知论证及其之间的关系推出这些论证的可接受性。 接下来，首先介绍上述主要的推理类型，然后分析与这些类型的推理相对应的人工智能 逻辑研究方向。接着，分析人工智能逻辑的基本研究方法：知识的表示与推理。最后，介绍本 书的内容和结构。 1.1 常见的推理类型 1.1 常见的推理类型 1.1.1 演绎推理与非单调推理 从已有知识到新知识的推理 关于从已有知识到新知识的推理，首先遇到的是“知识”这一概 念。从抽象的角度看，知识是知道者与命题之间的某种关系[3]。例如，“小张知道小王周末会 到浙江大学开会”，表达的是知道者（“小张”）与命题（“小王周末会到浙江大学开会”）之间的 关系。通常，把这种关系称为命题态度。常见的命题态度包括知道、相信、愿望、意图等。在 讨论知识的时候，可以先不考虑与知识关联的主体，而仅仅考虑用于表示知识的命题。通常， 可以把命题理解为有真假值的语句。 给定用命题表示的知识，可以从这些知识出发，通过推理得到新知识。主体所拥有的知 识有着不同的特点，如不完备性、不一致性、不确定性等。这些特点对知识的表示语言和推 理机制推出不同的要求，因此需要各种不同的推理类型。 演绎推理 第一种典型的推理类型称为演绎推理。演绎是一种可以“保真”的推理形式。在这 里，保真指的是在一个推理形式中，如果前提为真，则结论必然为真。 演绎可以用于表示从一般原理到特殊事例的推理关系。 例题1.1 来自这个袋子的豆子都是白色的。 这些豆子来自这个袋子。 因此，这些豆子是白色的。 这个演绎论证也称为三段论。该三段论的大前提描述一般原理，小前提描述特殊事例，结 论描述该特殊事例具有一般原理所描述的性质[4]。 通常，用有效性来刻画一个演绎论证的好坏。我们说一个演绎论证是有效的当且仅当：如 果该论证的前提为真，则其结论也必然为真。换句话说，如果一个演绎论证不是有效的，则 它不能保真。此时，我们称之为谬误。 演绎论证的有效性可以通过论证的形式来刻画。例1.1中的论证的形式可以表示为： 例题1.2 所有M都是P。 所有S都是M。 因此，所有S是P。 一般地，对于任何一个论证形式，它是有效的，当且仅当，对该论证形式中的变项所作 的任一解释，都不会出现前提为真而结论为假。 重要的是，演绎论证的有效性取决于其中各个命题的形式，而与各个命题的真假无关。这 个特性为建立形式化的演绎推理系统奠定了基础。 演绎推理具有单调性，意指如果一个演绎论证的结论为真，那么当出现新前提时，该论 证原来的结论保持为真。 3 1.1 常见的推理类型 非单调推理 在上述演绎论证中，各个命题都表示了确定的信息。如果信息是不确定的、不 完备的或不一致的，则无法直接套用上述推理形式而得到可靠的结论。其中，信息的不确定 性指的是缺少准确的知识来得到完全可靠的结论。大多数信息在某种程度上是不确定的。信 息不完备性指的是有些信息的缺失，比如，在一场牌局中，一个玩家并不知另一玩家手上的 牌。信息的不一致性指的是存在一对互相矛盾的命题。 例题1.3 鸟会飞。 Tweety 是鸟。 因此，Tweety会飞。 上述例子不是一个有效的演绎推理形式，原因是“鸟会飞”这个命题所表达的知识具有不 完备性和不确定性。一方面，“鸟会飞”中的“鸟”没有包含所有的鸟。由于缺乏那些不会飞的鸟 的信息，因此从知识的层面上看，上述论证所包含的知识是不完备的。另一方面，在“鸟会飞” 这个大前提下，关于某只具体的鸟，它是否会飞具有不确定性。 由于上述原因，如果直接套用演绎推理形式，则有如下两种可能的结果： 第一，把前提“鸟会飞”替换为“所有鸟都会飞”，而得到如下的推理： 例题1.4 所有鸟都会飞。 Tweety 是鸟。 因此，Tweety会飞。 这个推理在形式上是有效的，但由于“所有鸟都会飞”表达的含义不同于“鸟会飞”，因此无 法得到合理的结论。 第二，把前提“鸟会飞”替换为“有些鸟会飞”，而得到如下的推理： 例题1.5 有些鸟会飞。 Tweety 是鸟。 因此，Tweety会飞。 这是一个无效的推理形式。因此，也无法得到合理的结论。 由上述例子的分析可见，形式上有效的推理形式只适合于表达确定的、完备的知识。对 于不确定的或不完备的知识，通常存在例外情况。在上述例子中，“鸟会飞”意指通常情况下鸟 会飞，但存在例外，如“企鹅不会飞”、“受伤的鸟不会飞”等。 为了对不完备知识进行推理，可以在演绎推理中使用“正常性假设”，并由此形成基于假设 的演绎推理。为了与基于假设的演绎推理相区分，在本书中，把不含假设的演绎推理称为经 典演绎推理。 例题1.6 鸟会飞，除非可以证明它不正常。 Tweety 是鸟。 因此，Tweety会飞。 4 1.1 常见的推理类型 在这里例子中，如果从现有知识出发不能证明Tweety不正常，那么可以得到暂时性的结 论“Tweety 会飞”。由于假设经常会被新信息推翻，基于假设的演绎推理所得到的结论也会被推 翻。例如，当有信息显示Tweety是企鹅（因此Tweety不正常），则结论“Tweety会飞”被推翻。 通常，把结论可以被新信息推翻的推理称为非单调推理。因此，基于假设的演绎推理是一种 非单调推理。 对于上述的例外情况，除了在演绎推理中使用“正常性假设”，也可以通过把包含例外的 知识表示成可废止规则。一般地，可废止规则可以表示为“典型地，如果𝐴则𝐵”，意指一般 情况下，如果𝐴成立，则𝐵也成立，但𝐵可以被反面证据所推翻。用可废止规则描述的一般 原理可以被理解为常识。常识具有一定的普遍性，但允许存在例外。一般地，把基于可废止 规则的推理称为可废止推理。因此，可废止推理是另外一种非单调推理。 例如，“鸟会飞”可以被表示一条为可废止规则：典型地，如果𝑋是鸟，则𝑋会飞。这时， 如果“Tweety 是鸟”成立，则可以在没有反面证据的前提下，推出“Tweety会飞”。 这种推理关系时可废止的，因为当出现新信息时，允许已经得到结论可以被推翻。例如， 如果有新信息“Tweety是企鹅”且“企鹅不会飞”，则会得到“Tweety不会飞”的结论，即推翻原有 结论“Tweety 会飞”，因此这种推理是非单调的。 综上所述，非单调推理是演绎推理的扩展。扩展的方法有多种，包括把不确定、不完备 的知识表示为假设或可废止规则。非单调推理的典型应用包括常识推理和规范推理等。其中， 常识推理是指含有常识命题或常识句的推理。例1.3中的“鸟会飞”是一个常识命题。常识命题 的典型特征是它们在一般情况下成立，但在例外情况下不成立。规范推理广泛存在于法律和 道德伦理领域。规范可以被表示为可废止规则。 1.1.2 归纳推理与溯因推理 从案例归纳出新知识 日常生活中，人们从观察到的案例来推测一般的原理。当观察事例都 为真时，可以在一定程度上支持所推测的一般原理为真，但不能确保其为真。我们把这种从 观察事例到一般原理的推理模式称为归纳推理。相应地，如果一个论证中的推理关系为归纳 推理，则称之为归纳论证。 下面是一个归纳论证的例子： 例题1.7 这些豆子来自这个袋子。 这些豆子是白色的。 因此，来自这个袋子的豆子都是白色的。 归纳推理有广义的和狭义的两种的定义。前者是指任何不能保真的推理形式，即任何非 演绎推理；后者是指从特定事例的观察中推断出一般规律或原理的过程。在本书中，归纳推 理采用的是狭义的定义。 通常，用归纳强度来刻画一个归纳论证的好坏。一个归纳论证是否有说服力取决于其归 纳强度是否足够以及前提是否为真。 5 1.1 常见的推理类型 在从观察事例到一般原理的推理中，由于存在不确定性，通常采用概率来定量地刻画不 确定性。对于范畴句子“所有𝑋有性质𝑃”，并非所有情况都可以用它来描述。例如，有些时 候需要放松量词“所有”的限制，去度量其中的一部分对象有性质𝑃；有些时候需要放松性质𝑃 的限制，去度量特定对象满足性质𝑃的程度；有些时候需要度量主体相信整个句子为真的程 度。用于刻画这三种不确定性的理论分别称为客观概率、模糊理论和主观概率[3]。 从观察现象到最佳解释的推理 理机制也不同。决定逻辑语言和推理机制的常见知识特点包括：（1）知识的不确定性、不一 致性和不完备性；（2）命题态度。 经典演绎逻辑 对于确定的、完备的、一致的知识，可以采用经典演绎逻辑所提供的逻辑语 言和推理机制。 经典演绎逻辑包括命题逻辑和一阶逻辑。其中，经典命题逻辑以简单命题作为基本单位， 研究如何从简单命题出发通过联结词构造复合命题，并在此基础上研究复合命题之间的可推 导性关系。一阶逻辑在命题逻辑的基础上，研究包含谓词和量词的命题的结构规律以及这些 命题之间的可推导性关系。 由于经典命题逻辑是经典一阶逻辑的子集，而一阶谓词逻辑基本足以表示各类知识，因 此在下文中若不引起混淆，一般只提经典一阶逻辑。 一阶逻辑具有很强的表达能力，但计算复杂度高。在实际的应用中，往往只需要选用一 阶逻辑中表达能力较低而可计算性较好的片段。在语义Web和知识图谱的应用背景下，用于 刻画概念、角色、个体以及它们之间关系的逻辑语言比一阶逻辑简单。通常把这种逻辑语言 称为描述逻辑。 7 1.2 人工智能逻辑主要研究方向 非单调逻辑 当知识存在不完备性和不一致性时，经典一阶逻辑不足以提供合适的表示语言 和推理机制，需要加以扩展，形成各种非单调逻辑。 一方面，对于不完备的知识，往往存在例外，而经典一阶逻辑无法表达例外。 例题1.11 例外之间可能产生冲突。在上述例子中，“转动点火钥匙，发动机启动”和“由于油缸中没有汽 油，发动机不启动”的两个结论相互矛盾。又如，对于实践推理，不同的规范之间可能存在冲 突。考虑如下例子： 例题1.12 有个智能服务机器人依据如下两条规范进行决策：“当用药时间到的时候，（为了保 护病人的健康）应该给他服药”，“当病人正在忙的时候，（为了保护病人的自主权）不应该给他 和特定命题的可证明性的关系。一条缺省规则由三部分组成：“如果前提条件:辩护条件，那 么结论”。给定一条缺省规则，当其前提条件可证，而辩护条件的反面不可证时，可以推出结 论。例如，“转动点火钥匙：发动机启动/发动机启动”是一条缺省规则。当处于“辩护条件”位置 的“发动机启动”的反面，即“发动机无法启动”不可证时，可以推出“发动机启动”这个结论。因 此，如果在一个知识库中，只包含这条缺省规则和一个事实“转动点火钥匙”，那么可以推出“发 动机启动”的结论。值得注意的是，由缺省规则推出的结论是暂时的，新信息的出现可能推翻 原有结论。由于当新信息出现时，原有的结论允许被推翻，具备这种推理机制的逻辑也被称 为非单调逻辑。在这个例子中，如果添加新知识：“如果油缸中没有汽油，那么发动机无法启 动”和“油缸中没有汽油”，则“发动机无法启动”可证，因此“辩护条件”的反面成立，原来的结论 不能被推出，需要被收回。由此可见，通过运用缺省规则，可以提高经典一阶逻辑的表达能 力，实现对不完备知识的表示和推理。 第二，通过添加可废止规则。可废止规则通常用于表达如下类型的知识“典型地/在一般情 况下，如果𝐴那么𝐵”。对于这样的规则，当前提𝐴成立时，有较充分的理由相信𝐵成立，但 允许存在例外。与缺省规则不同的是，在可废止规则中，例外没有明确表示出来。相反，在缺 省规则中，辩护条件可以对应到例外的存在性。 8 1.2 人工智能逻辑主要研究方向 由上述第一种方法构造的非单调逻辑系统包括缺省逻辑、回答集编程等。由第二种方法 构造的非单调逻辑系统包括可废止逻辑、论辩系统等。 关于知识和信念的逻辑 当知识与认知主体的心智状态（如信念、愿望、意图等）有关时，经 综上所述，人工智能逻辑研究可以对各类知识进行表示和推理的逻辑学理论。本书包括 如下五个部分。 第一部分是绪论与预备知识。这一部分除了本章的内容，将在第二章介绍本书其他章节 需要用到的预备知识。 第二部分是经典演绎逻辑，包括命题逻辑、一阶逻辑和描述逻辑。在命题逻辑和一阶逻 辑部分（第三、四章），着重介绍在计算机和人工智能领域有广泛应用的消解原理。作为语义 Web 能领域长期面临的问题。为了解决该问题，需要对一阶逻辑进行扩展，由此产生各种具有一 定灵活性的逻辑系统，即非单调逻辑系统，包括缺省逻辑、回答集编程等。其次，从案例归 纳出新知识的角度看，概率论是建模不确定性的基本工具之一。在此基础上，可以研究观察 证据和假说之间的关系（贝叶斯网络、因果推断），观察证据与一般规则的关系（归纳逻辑编
